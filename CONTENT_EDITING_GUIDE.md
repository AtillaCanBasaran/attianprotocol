## Voice Rule

- The archive narrator refers to herself as `Administrator`.
- Do not use the sealed name in public-facing copy.
- If old origin lore needs to mention the naming attempt, describe it as a rejected or sealed label.

## Navigator Search Responses

For normal manual additions, edit:

`scripts/navigator-response-data.js`

Add one object to `window.NAVIGATOR_RESPONSE_BANK` with:

- `terms`: words or phrases visitors may type
- `speaker`: `administrator`, `muse`, or `red`
- `text`: the response shown under the Navigator search bar

The Navigator automatically loads this file and displays the matching avatar frame. This is now the single source of truth for Navigator responses.

## Generated Visual Archive Copy

Some visible card text is generated by JavaScript rather than written directly in HTML.

For future manual entries, edit `scripts/archive-content-data.js`.

`scripts/visual-archive.js` is the renderer and still contains older base metadata. Avoid editing it for ordinary content additions unless changing layout or behavior.

Use `scripts/archive-content-data.js` for:

- Creature card metadata: `creatureMeta`
- Artifact card metadata: `artifactCatalog`
- Generated Artifact Vault manifest: `artifactItems`
- Generated Creature Index manifest: `creatureItems`
- Optional artifact type families if a new image family is added later

Filename conventions used by the generated archive:

- Creatures: `images/creatureindex/creature7.png` and optional `images/creatureindex/creature7_original.jpeg`
- Artifacts: `images/artifactvault/drawing2.png`, `images/artifactvault/memory5.png`, `images/artifactvault/mini4.png`
- Originals: add `_original` before the extension when available
- Optimized preferred formats: add `.avif` and `.webp` beside the original.
- Thumbnail preferred formats: add `_thumb.avif` and `_thumb.webp` beside restored display images.
- Creature entries render as collectible card fronts with full contained artwork, types, six shared stats, inspectable skills, a short profile, and a structured quest.
- Use the same stat order for every creature: `Power`, `Speed`, `Courage`, `Wisdom`, `Charisma`, `Stealth`. Give every `skillSet` name a matching short entry in `skillDetails`.
- Long stories, field metadata, source links, and Administrator review live in the optional lore shelf inside each card.
- Keep the restored PNG at full resolution; each Creature Index card links directly to it for inspection in another tab.
- Keep `_original` PNG/JPEG source fragments as fallback, backup, and comparison material.

Detailed recipes and examples are in `docs/CONTENT_AUTHORING_GUIDE.md`.

## Visitor Terminal State

Visitor Terminal is intentionally offline for now because the Supabase backend is inactive until the final version.

- Do not re-add Supabase calls unless the user asks to reactivate it.
- Keep the page red/offline through `body.visitor-offline-page`.
- Keep the Navigator entry marked as offline while the terminal is sealed.
- If reactivated later, update the Visitor Terminal page, Navigator label, CSS state, and Update Log together.

## Update Log Rule

When changing visible site behavior or content structure, add a new patch entry at the top of:

`memory_node/attian/updatelog/index.html`

Do not replace older entries. The update log is append-at-top only.
