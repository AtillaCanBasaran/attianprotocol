# Attian Protocol Content Editing Guide

This file is the quick map for changing visible text without searching the whole project.

## Voice Rule

- The archive narrator refers to herself as `Administrator`.
- Do not use the sealed name in public-facing copy.
- If old origin lore needs to mention the naming attempt, describe it as a rejected or sealed label.

## Generated Visual Archive Copy

Some visible card text is generated by JavaScript rather than written directly in HTML.

Edit `scripts/visual-archive.js` for:

- Creature card metadata: `creatureMeta`
- Future creature slot defaults: `defaultCreatureMeta`
- Artifact categories: `artifactTypes`
- Generated artifact card text: `artifactCard`
- Featured artifact block: `loadArtifacts`

Filename conventions used by the generated archive:

- Creatures: `images/creature7.png` and optional `images/creature7_original.jpeg`
- Artifacts: `images/drawing2.png`, `images/memory5.png`, `images/mini4.png`
- Originals: add `_original` before the extension when available

## Global Text

- Legal footer: `scripts/legal-footer.js`
- Restricted page password overlay: `scripts/restricted-access.js`
- Main entry page behavior: `scripts/main-page.js`
- Site-wide visual styling: `css/style.css`

## Update Log Rule

When changing visible site behavior or content structure, add a new patch entry at the top of:

`memory_node/attian/updatelog/index.html`

Do not replace older entries. The update log is append-at-top only.
